# SyncCampus Teacher Dashboard

Design the teacher dashboard for **SyncCampus** with the same visual language as the student dashboard: clean, minimal, refreshing, and extremely easy to use.

The teacher should be able to open the dashboard and immediately see:

1. What lecture they have now
2. What lecture is next
3. Their complete schedule
4. Any schedule changes
5. Simple controls to manage their lectures

The interface should not feel like a complicated college ERP system.

# 13. Teacher Permissions

Teacher permissions should be limited to their assigned lectures.

### Teacher can:

✓ View their timetable  
✓ View assigned classes  
✓ View classrooms  
✓ Cancel their lecture  
✓ Reschedule their lecture  
✓ Change classroom  
✓ Receive notifications  
✓ View announcements  

### Teacher cannot:

✕ Modify another teacher's timetable  
✕ Modify official exam dates  
✕ Create/delete student accounts  
✕ Change college-wide settings  
✕ Modify another department's schedule  

Those controls belong to the **Admin**.

---

# 14. Confirmation Before Important Changes

Do not allow important changes with one accidental click.

For example, when the teacher clicks Cancel:

**Cancel this lecture?**

Database Management System  
10:00 AM – 11:00 AM  
Room 204

This action will notify the affected students.

**[Go Back] [Confirm Cancellation]**

Use the same approach for rescheduling and room changes.

---

# 15. Automatic Synchronization

This is the most important part of the teacher interface.

Example:

Teacher:

**Change Room**

204 → 305

↓

SyncCampus updates the central timetable

↓

Teacher sees:

**Room 305**

↓

Affected students see:

**🔔 Room Changed**

DBMS will now be conducted in **Room 305**.

The teacher should not have to separately inform every student.

---

# 17. Visual Design

Keep exactly the same design language as the student dashboard.

Use:

- White cards
- Light blue background
- Blue primary actions
- Rounded corners
- Subtle shadows
- Clean icons
- Large readable text
- Plenty of whitespace

For teacher actions:

**Blue:** normal actions  
**Red:** cancellation  
**Green:** successful update  
**Neutral:** secondary actions

Avoid making every button colorful.

# Core Principle

The student dashboard answers:

> **"What do I have?"**

The teacher dashboard answers:

> **"What do I have, and what do I need to manage?"**

The teacher should be able to manage a lecture in **a few clicks**, while SyncCampus automatically communicates the change to every affected student.
